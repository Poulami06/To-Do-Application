# 📝 My Mini Task App

A clean, responsive, and minimalist To-Do application built using vanilla JavaScript, HTML5, and Bootstrap 5.

---

## ✨ Features
- **Add Tasks**: Quickly create tasks by typing and clicking the button.
- **Input Validation**: Prevents adding empty tasks with immediate user feedback.
- **Delete Tasks**: Remove individual completed or unwanted tasks on the fly.
- **Clean UI**: Minimalist pastel card interface centered for focus and ease of use.

---

## 🛠️ Tech Stack
- **HTML5** — Semantic layout and structural markup
- **CSS3 / Bootstrap 5** — Responsive styling, soft pastel aesthetics, and card components
- **JavaScript (ES6)** — DOM manipulation and dynamic event handling
